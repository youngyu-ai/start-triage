🌟 大量傷病患 (MCI) 檢傷宗旨

核心理念：「在最短的時間內，利用有限的資源，救活最多的人！」
(Do the greatest good for the greatest number of people.)

當現場「傷患人數與嚴重程度」遠超過「第一線救援資源」時，即構成大量傷病患事件。此時教官要求大家必須立刻轉換平時的急診思維：

  • 快速評估不卡關： 每位傷患僅能停留 30 秒評估，絕不戀戰。
  • 最少急救處置： 檢傷當下僅執行「暢通呼吸道」與「控制大血管出血」兩種救命動作。
  • 殘酷但必要的妥協： 必須忍痛放棄平時可能救得活、但在災難現場會耗盡全隊資源的極重度傷患 (黑標)，將寶貴的醫療與後送資源，保留給存活率高且極需救治的傷患 (紅標)。

📖 START 檢傷四大步驟 (RPM)

在進入下方互動模擬前，請先熟記「1走、2呼吸、3循環、4意識」的三十秒判斷法則。現場不是急診室，請把時間留給最危急的人！

  • 步驟一 (走)：能聽從廣播自行走動者 ➔ 🟢 綠色 (輕傷)
  • 步驟二 (R 呼吸)：
    ▪ 無呼吸：暢通氣道 ➔ 若仍無呼吸 ⬛ 黑色 / 若恢復呼吸 🔴 紅色
    ▪ 有呼吸：測速率，若 >30 或 <10 次/分 ➔ 🔴 紅色 (若在 10~30 次之間，則進入下一步)
  • 步驟三 (P 循環)：微血管充填時間 (CRT) 大於 2秒 或摸不到橈動脈 ➔ 🔴 紅色
  • 步驟四 (M 意識)：無法遵從簡單指令 ➔ 🔴 紅色。
    若以上全部過關 ➔ 🟡 黃色 (中度)。
